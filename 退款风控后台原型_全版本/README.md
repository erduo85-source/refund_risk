# 退款风控中心原型

这是一个不依赖任何外部库的静态后台原型完整包，包含：

- 游戏项目维度切换
- 受控用户列表、筛选、批量操作
- 用户详情与风险轨迹
- 封禁 / 解封确认流程
- Apple App Store / Google Play 退款记录
- 封禁触发、补款解封、渠道接入与执行策略
- 风险概览和操作日志

## 本地运行

以下页面均可直接双击打开，无需安装依赖或联网：

- `index.html`：基础版本，需要与同目录的 `styles.css`、`app.js` 一起保留。
- `版本2.html`：策略卡片与策略抽屉版本，单文件运行。
- `版本3.html`：退款策略和受控用户配置优化版本，单文件运行。
- `版本4.html`：增加平台级深蓝顶部导航的最新版本，建议优先查看，单文件运行。

也可以使用任意本地静态文件服务器预览。此文件夹只包含后台原型，不包含独立的用户端补款页面。
